# 내시간에

동네 정비소·출장 업체를 찾고, 손님이 원하는 시간에 맞춰 예약하는 사이트.

- `python3 build.py` → `_site/`에 정적 사이트 생성
- 데이터: `data/raw/` 에 공공데이터포털 **전국자동차정비업체표준데이터.csv** 를 넣으면 전국 데이터로 만들어져요.
- 공개 지역: `config.json` 의 `released_regions` 에 지역을 추가하면 그 지역 페이지가 생기고 사이트맵에 들어가요. 색인 비율을 보면서 조금씩 늘려요.
- `contact_email`(정보 수정·삭제 요청 받는 곳), `kakao_js_key`(전화번호 실시간 찾기) 를 채워야 해요.
- main 에 올리면 GitHub Actions 가 자동으로 만들어 배포해요.
